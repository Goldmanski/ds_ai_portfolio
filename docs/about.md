# About

## From curiosity about technology to building with it

My path into technology did not start with a traditional Computer Science background.

It started with curiosity.

I became interested in understanding how software works, how data can be turned into useful information, and eventually how AI can become part of real applications.

That curiosity gradually turned into a more structured direction: **Data Science, AI and Software Engineering.**

---

## Learning by building

I learn best when theory becomes something I can actually build.

That is why this portfolio is centred around projects rather than isolated exercises.

Some started with a dataset and a simple question.

Others started with a practical problem that could be turned into an application.

Along the way, I have worked with data analysis, Machine Learning, language models, embeddings, semantic search and software architecture.

Each project represents a different part of that journey.

---

## From data to applications

My projects increasingly move beyond analysing data alone.

I am interested in what happens after the analysis.

How can a model become part of an application?

How can an LLM work together with traditional Machine Learning?

How should AI interact with deterministic software?

How can a system remain understandable and maintainable as it becomes more complex?

These questions are what connect the projects in this portfolio.

---

## What I am building towards

I want to develop towards roles where **Data Science, AI and Software Engineering meet**.

I am particularly interested in building systems where models are not isolated experiments, but useful components of a larger application.

That means understanding not only how to work with a model, but also everything around it:

**data → models → applications → infrastructure**

---

## A portfolio, not a finish line

This portfolio is a snapshot of an ongoing learning process.

The projects here are not meant to suggest that I have finished learning.

Quite the opposite.

Each project has raised another question, exposed another limitation or opened another direction to explore.

And that is exactly what I find interesting about technology.

> **The more you learn, the more interesting the questions become.**
